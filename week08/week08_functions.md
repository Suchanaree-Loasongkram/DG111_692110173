# Week 8 — Functions Reference

**Function Reference — `ex02_game_utils.c`**

| Function                                    | ทำหน้าที่                                                 | Returns                      |
| ------------------------------------------- | ------------------------------------------------------------------ | ---------------------------- |
| `int clamp(int value, int min, int max)`  | จำกัดค่า value ให้อยู่ระหว่าง min และ max | ค่าที่ clamp แล้ว  |
| `float lerp(float a, float b, float t)`   | Linear interpolation ระหว่าง a และ b ตาม t            | ค่าที่คำนวณได้ |
| `int randomRange(int min, int max)`       | สุ่มตัวเลขระหว่าง min และ max                  | ค่าสุ่ม               |
| `float percentOf(int current, int total)` | คำนวณเปอร์เซ็นต์                                   | ค่าเปอร์เซ็นต์ |

## คำถาม Reflection — Exercise 2

### 2.1 `clamp` — Pass by Value

**คำถาม:** ทำไม `hp` ใน `main()` ถึงยังเป็น 150 ทั้งที่ `value` ใน `clamp()` ถูกเขียนทับเป็น 100 ไปแล้ว?

**คำตอบ: hp ใน main() และ hp ใน clamp() เป็นคนละตัวแปรกัน ตามหลักการ Pass by Value ของภาษา c เมื่อเรียกฟังก์ชัน ค่าของ hp จะถูกคัดลอกไปเก็บไว้ในตัวแปร value ของฟังก์ชัน clamp() ค่าที่เปลี่ยนไปจึงมีเพียง value ที่ค่า hp ถูกคัดลอกไปเก็บไว้เท่านั้น**

### 2.2 `lerp` — Local Scope

**คำถาม:** ทำไม `main()` ถึงมองไม่เห็นตัวแปร `result` ทั้งที่มันถูกประกาศไว้ในไฟล์เดียวกัน?

**คำตอบ: เป็นเรื่องของ scope ของตัวแปร result ไม่ใช่ตัวแปร global แต่เป็นแค่ตัวแปร local ในฟังก์ชันของ lerp() เท่านั้น ตัว main() จึงไม่สามารถมองเห็นตัวแปรที่ถูกประกาศในฟังชันก์อื่นได้**

### 2.3 `randomRange` — Pass by Value

**คำถาม:** ทำไม `diceMin` ใน `main()` ถึงยังเป็น 1 ทั้งที่ `min` ใน `randomRange()` ถูกบวกเพิ่มเป็น 101 ไปแล้ว?

**คำตอบ: หลักการ Pass by Value ของภาษา c ทำให้diceMin ยังมีค่าเป็น 1 เพราะเมื่อเรียกใช้ฟังก์ชัน ค่าของ diceMin จะถูกคัดลอกไปเก็บไว้ในตัวแปร min ของฟังก์ชัน ในบรรทัดของการคำนวณ ค่า min เป็นตัวที่ถูกใช้ในการคำนวณ ค่าของ diceMIn จึงไม่ได้ถูกเปลี่ยน เพราะมันคือค่าที่ถูกคัดลอกไว้ ไม่ใช่ค่าที่ถูกเขียนทับ**

### 2.4 `percentOf` — Pass by Value

**คำถาม:** ทำไม `score` ใน `main()` ถึงไม่เปลี่ยนเป็น 0 ตาม `current` ทั้งที่ `percentOf()` แก้ `current = 0;` ไปแล้ว?

**คำตอบ: หลักการ Pass by Value ของภาษา c ทำให้ score ใน main() ไม่เปลี่่ยนเป็น 0 ตามที่ถูกเปลี่ยนในฟังก์ชัน ค่าของ score เพียงถูกคัดลอกไปเก็บไว้ในตัวแปร current ของฟังก์ชัน เมื่อ current เป็น 0 ค่าของ current จึงเป็น 0 เพียงค่าเดียว ไม่ได้เปลี่ยนค่า score ไปด้วย**
